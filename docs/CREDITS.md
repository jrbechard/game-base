# Credits

Every outside asset used in the game is listed here: who made it, where it came from, its licence,
and where it is in the project. **Add a line whenever an outside asset is added.** (A game's credits
screen should show the same list.) A game started from `game-base` keeps the lines below, since the
base ships these files.

## Fonts

| Font | Made by | Source | Licence | Used for | Where it is in the project |
|---|---|---|---|---|---|
| Inter (Regular and Bold, 18 pt cut) | The Inter Project Authors (Rasmus Andersson) | https://rsms.me/inter/ | SIL OFL 1.1 | the base's default font (`Assets/Theming/theme_main.tres`) | `Assets/Fonts/Inter_18pt-*.ttf`, licence `OFL_Inter.txt` |

A game that picks its own font replaces the default in its own `theme_main.tres` and lists the new
font here. The OFL needs the licence text to travel with the font files, and the fonts must not be
sold by themselves.
